## 纯 IPLC 专线定位与套餐折扣实算

**闪跃（shanyue / FlashLeap）** 在品牌矩阵中归入中高端专线梯队（`premium-line`），核心卖点围绕“顶级 IPLC 纯专线”“骨干网接入”与“原生 IP 全解锁”展开。

价格表共设 5 档，结构紧凑，没有设置一次性不限时流量包：

- **闪跃年付版**：`¥96 / 年`（每月 60GB，折算 ¥8/月），**不适用** `shanyue` 优惠码。
- **闪动（Flicker）月付**：原价 `¥24 / 月`（150GB），若叠加 `shanyue` 8 折码，折后约 `¥19.2 / 月`（约 ¥0.128/GB）。
- **飞跃（Leap）月付**：原价 `¥44 / 月`（300GB），8 折后约 `¥35.2 / 月`。
- **瞬移（Teleport）月付**：原价 `¥84 / 月`（600GB），8 折后约 `¥67.2 / 月`。
- **跃迁（Warp）月付**：原价 `¥134 / 月`（1000GB），8 折后约 `¥107.2 / 月`。

单看闪动档叠加 8 折后的成本（¥19.2/150GB），其纸面性价比甚至略优于不少 ¥20–¥25 原价月付档；但要注意优惠码的长期有效性（是否仅限首单或长期复购）尚未联网核实，需在结账页确认，也可参考 [优惠码查询汇总](/brands/coupons/)。

## 专属客户端限制与技术透明度缺口

选择闪跃之前，必须清楚它带来的两项硬约束：

1. **强制专属客户端，彻底无订阅链接**：资料明确写明闪跃目前转为“闪跃专属客户端（不提供订阅链接）”。如果你需要在软路由部署、在 Linux 无头终端运行，或依赖 [Clash Verge Rev](/clients/clash-verge-rev/) / [Shadowrocket](/clients/shadowrocket/) 维护自己的分流规则集，闪跃无法满足工作流要求。
2. **底层协议与开业年份未公开**：清单第 19 条基础信息明确标注“协议：原文未标注”，且品牌成立年份亦为待核实状态。对于中高端定价品牌而言，这两项信息透明度的缺失降低了可审计性。

## 历史参考速度与试错建议

根据 2026-10-19 的非晚高峰历史简表，闪跃香港参考值表现靠前（延迟 23ms、下载 548Mbps），台湾 38ms / 110Mbps、日本 53ms / 144Mbps、新加坡 44ms / 383Mbps、美国 143ms / 18Mbps；AI 方面标注支持 ChatGPT/Claude，Gemini 在“支持”与“视节点而定”间存在细微差异。

因为缺少真实的 20:00–23:00 晚高峰多网测试，**不建议未经试跑直接锁入 ¥96 年付版**（况且年付版不享受 8 折码）。如果能接受专属客户端，先尝试用 `shanyue` 优惠码购买一月“闪动（150GB）”实测本地晚高峰表现是更稳妥的做法；若你必须使用第三方订阅，可转向同库中的 [一翻云](/brands/yifan/) 或通过 [品牌横向对比](/compare/) 另选。
