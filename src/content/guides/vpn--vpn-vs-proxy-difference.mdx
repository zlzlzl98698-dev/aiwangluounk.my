faqs:
  - q: "为什么说传统商业 VPN 在国内越来越难用了？"
    a: "因为传统商业 VPN（如 ExpressVPN、NordVPN 等）采用的协议（如 OpenVPN、IKEv2 甚至标准的 WireGuard）在握手阶段具有非常明显的数据包指纹和固定端口特征。中国国家级防火墙（GFW）部署的深度包检测（DPI）技术可以近乎 100% 识别此类隧道并瞬间丢包阻断，导致商业 VPN 出现频繁连不上、几分钟就掉线或速度极慢的现象。"
  - q: "开启 VPN 后为什么国内微信和淘宝打开变慢了？"
    a: "因为传统 VPN 默认创建虚拟网卡接管系统全局流量。当你开启 VPN 访问国内的微信、网易云音乐或淘宝时，你的数据包会先绕行到 VPN 的海外服务器（如美国或日本），再从海外访问国内服务器，形成严重的跨国绕路，不仅延迟暴增，还会触发国内平台的异地登录风控。而代理软件（如 Clash / v2rayN）具备规则分流功能，国内流量直接在本地直连，完全不影响国内网络速度。"
  - q: "代理软件安全吗？它能提供像商业 VPN 一样的高度匿名隐私吗？"

  - q: "Clash 的 TUN 模式是不是就等于 VPN？"
    a: "TUN 模式在「操作系统接管层级」上借用了 VPN 的机制（通过创建虚拟网络适配器接管所有未配置代理的程序流量，解决部分软件不支持 Socks5 代理的问题），但在「流量分发底层」，它依然运行着代理核心的规则分流引擎。也就是说，TUN 模式既拥有 VPN 强制接管全局的能力，又保留了代理按域名与 IP 智能分流的优势。"

## 概念混淆的源头：商业包装与真实技术模型

在很多非技术用户的语境中，常常把“翻墙软件”统称为“VPN”。无论手机上装的是 Shadowrocket、Clash 还是某款海外商业 VPN，大家口头上都习惯说“我开个 VPN”。

然而在计算机网络与信息安全的真实语境下，**VPN（Virtual Private Network）** 与 **代理（Proxy）** 是两种诞生于不同历史背景、服务于完全不同目标的网络技术体系。

---

## VPN 与代理的底层维度终极全景对照表

为了彻底理清技术边界，我们整理出以下十个关键维度的对比表：

| 技术指标 | 传统商业 VPN（如 WireGuard / OpenVPN） | 现代现代代理（如 Shadowsocks / VLESS / Trojan） |
| :--- | :--- | :--- |
| **设计初衷** | 企业远程办公、跨地域内网互联、全数据防窃听 | **对抗深度包检测（DPI）、规避封锁、智能分流** |
| **OS 协议栈层级** | 网络层（Layer 3，IP）或数据链路层（Layer 2） | 传输层/应用层（Layer 4 至 Layer 7，TCP/UDP/TLS） |
| **流量接管方式** | 操作系统级虚拟网卡（TAP/TUN），**默认全量接管** | 依赖系统代理端口（HTTP/Socks5）或客户端 TUN 模式 |
| **智能分流能力** | **极弱**（通常为全局出国，国内国外全走海外服务器） | **极强**（支持基于 GeoIP、域名后缀、进程名的毫秒级分流） |
| **特征隐蔽性（抗封锁）** | **差**（握手协议特征鲜明，易被防火墙特征阻断） | **极佳**（伪装成标准 HTTPS 流量，流量混淆度极高） |
| **国际访问性能** | 加密负载大，跨国握手开销高，易受 QoS 限速 | 轻量协议设计，支持多路复用（Multiplexing），速度极快 |
| **国内软件兼容性** | 极易导致微信、淘宝、网易云等国内 App 误判异地 | 国内流量 100% 本地直连，对国内日常软件完全透明无感 |
| **AI 工具解锁表现** | IP 多被 OpenAI/Claude 列入高风控黑名单，极易拦截 | 节点出口分散，支持针对 ChatGPT 单独分流至纯净节点 |
| **常见客户端形态** | 厂商打包的封闭 App，通常一键开关，无配置选项 | 开放开源客户端（Clash Verge Rev, v2rayN, Shadowrocket） |
| **多设备局域网共享** | 通常限制在同一 App 内，软路由或局域网放行较繁琐 | 极易在家庭局域网开启 Allow LAN，供电视盒子/游戏机共享 |

## 协议工作原理深度拆解

### 1. 传统 VPN：在公网上挖一条刚性的地下管道

VPN 最初是为跨国公司员工远程访问公司内网而设计的。它的逻辑非常直接：
在你的电脑与远端 VPN 服务器之间建立一条端到端加密的隧道。一旦通道建立，操作系统所有的网络发包都被封装在隧道协议（如 IPsec ESP 或 WireGuard 数据包）内部。

- **优势**：哪怕你在黑客充斥的机场公共 Wi-Fi 下上网，你的所有数据也是绝对加密的，黑客无法解析出你访问了什么网站。
- **致命软肋**：这个管道在防火墙面前太显眼了。防火墙看到你的电脑源源不断地向海外某固定 IP 发送毫无 HTTPS 特征的 UDP 大包，就会断定你正在使用加密隧道，直接向中间路由器下发指令重置连接或限速到 10Kbps。

### 2. 现代代理：像变色龙一样穿上合法商用外衣

与 VPN 截然相反，代理软件的核心哲学是**伪装与混淆（Obfuscation）**。
例如目前的标准协议 `Trojan` 或 `VLESS + Reality`：
当你的电脑向海外代理服务器发送请求时，数据包的握手过程、证书握手与 TLS 特征与你正常访问苹果官网（apple.com）或微架构网站完全一模一样。

- 深度包检测系统在审查该流量时，只能看到这是一条标准的合法企业级 HTTPS 浏览会话；
- 只有远端拥有私钥的代理落地机，才能剥离伪装，将真正的请求发送给目标网站。

## 场景选型决策指南

根据你的实际任务目标，选型应严格遵守以下原则：

1. **日常跨境冲浪、看 4K 流媒体、使用 ChatGPT**：**坚决选择现代代理服务（机场）**。只有代理工具的分流引擎才能让你一边用香港低延迟节点查资料，一边让 OpenAI 走美国出口，同时国内钉钉微信丝滑直连。
2. **极客玩外服网络游戏**：**选择游戏加速器或具备低丢包专线的代理**。不要使用常规商业 VPN 打游戏，因为其重加密握手会显著拉大往返延迟与抖动。
3. **跨国企业高机密商业办公与异地组网**：**选择自建 WireGuard 或企业级 VPN**。此时安全合规与私有网络互联是第一位，且企业专线通常有合规白名单保障。
