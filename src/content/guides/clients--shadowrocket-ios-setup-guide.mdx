## iOS 生态的常青树：为什么小火箭是 iPhone 用户首选？

在苹果封闭的 iOS 系统生态中，网络工具由于受到沙盒机制和后台常驻限制，开发难度极大。而 **Shadowrocket（由开发者 Shadow Launch Technology 开发）** 自诞生以来，凭借以下核心优势成为了装机量最大的统治级工具：

1. **极度亲民的定价**：在美区仅售 2.99 美元，一次性买断永久享受全量功能更新；
2. **全协议万能支持**：同时完美兼容 Shadowsocks、VMess、VLESS、Trojan、Snell 以及最新的 Hysteria 2、WireGuard 与 TUIC；
3. **直观易用的交互**：主界面一键开关、内置测速、自动按延迟排序，即便是没有任何技术背景的小白也能在 3 分钟内完成配置；
4. **低功耗后台保活**：基于 iOS Network Extension 深度优化，待机掉电极慢，整天挂在后台几乎不影响 iPhone 电池续航。

## 极简配置四步作业法（带图文逻辑）

```
[海外 Apple ID 登录 App Store 下载]
                 │
                 ▼
[首页右上角「+」──> 类型选 Subscribe ──> 粘贴订阅 URL ──> 点击保存]
                 │
                 ▼
[长按 Ping 测速 ──> 选中绿色低延迟节点 ──> 全局路由确认选择「配置」]
                 │
                 ▼
[打开顶部主开关 ──> 允许添加 VPN 配置 ──> Face ID 验证成功入网]
```

### 第一步：添加机场订阅链接

1. 登录机场服务商面板，复制专属的 **通用订阅链接（或小火箭一键导入链接）**；
2. 打开 Shadowrocket，点击主界面右上角的 **「+」加号** 按钮；
3. 在弹出的页面中，点击第一项 **「类型（Type）」**，下拉选中 **「Subscribe」**；
4. 在下面的 **「URL」** 文本框中，粘贴刚才复制的机场订阅链接；
5. 在「备注（Remarks）」一栏中，可以输入机场名称便于区分（如“光速云”）；
6. 点击右上角 **「保存（Save）」** 按钮。软件将自动开始向服务器发起拉取请求，稍等片刻，主界面就会整齐展示出该品牌下辖的所有节点。

### 第二步：快速测速与活动节点选定

1. 在节点列表上方，找到并点击 **「连通性测试（Ping Test）」**；
2. 软件将并发测试所有节点的真实 TCP / ICMP 响应延迟，并在节点右侧显示具体的数字（如 `32ms`、`65ms`）；
3. **轻触点击**一个延迟显示为绿色且数值较小的节点（推荐优先选择香港 01 或日本 01），节点左侧出现黄色或橙色圆点，表示该节点已被设为当前出境的活动通道。

### 第三步：核查全局路由分流模式

在主界面下方找到 **「全局路由（Global Routing）」** 选项：
- 务必确保其选中的状态为 **「配置（Config）」**（这是实现自动分流的唯一正确选项）；
- 严禁误点为「代理（Proxy）」，否则国内软件也会全部绕道海外。

### 第四步：启动连接与系统授权

1. 将主界面顶部最醒目的 **「未连接」** 开关向右拨动；
2. 首次开启时，iOS 系统会弹出系统级确认框：“Shadowrocket 想要添加 VPN 配置”；
3. 点击 **「允许（Allow）」**，并在弹出的密码验证界面中输入锁屏密码或验证 Face ID；
4. 开关变为已连接状态，状态栏或灵动岛出现小巧的「VPN」图标，恭喜你，配置全部大功告成！

## 高频故障排查急救箱

### 1. 订阅列表更新失败，提示「Timeout」

**解法**：在手机上断开当前 Wi-Fi，切换为蜂窝移动网络；在小火箭主界面找到该订阅组，向左滑动卡片并点击「更新」，通常即可绕过本地宽带对订阅域名的临时干扰。

### 2. 状态栏 VPN 频繁断开后重连

**解法**：进入小火箭底部「设置」-「TCP/IP 堆栈」，将默认设置切换至「轻量级」或「高级」模式，并检查是否开启了低电量省电模式。

### 3. 打开微信无法发送图片，或网易云音乐变灰

**解法**：检查全局路由是否误开成了「代理」。将其改回「配置」；若依然异常，在底部「配置」面板中点击更新当前分流规则文件即可。
