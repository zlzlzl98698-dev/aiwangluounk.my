## 经典开源标杆：为什么选择 v2rayN 与 v2rayNG？

在形形色色的代理客户端中，**v2rayN** 与 **v2rayNG** 始终占据着无可替代的生态地位。不同于许多基于商业公司包装的 App，它们由开源社区开发者完全出于对网络自由的热爱而长期维护。

这两款工具的最核心优势可以总结为：**纯粹、极轻量、协议支持第一线**。
如果你讨厌臃肿的商业广告、排斥复杂的配置脚本、单纯希望用最低的系统资源开销稳定连接网络，这对“双子星”组合就是最佳解法。

## Windows 端（v2rayN）完整配置步骤

```
[下载 with-Core 压缩包] ──> [解压至纯英文路径] ──> [添加订阅分组 URL] 
                                                        │
                                                        ▼
[系统代理：自动配置] <── [路由选择：绕过大陆] <── [更新订阅并测试延迟]
```

### 第一步：解压与目录规范

1. 从官方 GitHub 仓库（`2dust/v2rayN`）下载最新的 `v2rayN-with-Core.zip` 压缩包；
2. **重要规范**：将压缩包解压到一个**全英文路径的文件夹**中（例如 `D:\Tools\v2rayN`）。避免解压在包含中文或空格的路径下，否则底层的 Xray 内核在加载配置文件时可能触发编码异常。

### 第二步：添加与拉取订阅

1. 鼠标双击打开 `v2rayN.exe`，主界面弹出后，在顶部菜单栏点击 **「订阅分组」**，选择 **「订阅分组设置」**；
2. 在弹出的窗口左下方点击 **「添加」**；
3. 在右侧信息栏中，填写一个便于识别的备注名称（如“光速云”），在「可选地址（url）」一栏中**粘贴机场后台提供的 V2Ray/通用订阅链接**；
4. 点击右下角 **「确定」** 保存设置；
5. 回到主界面，再次点击顶部菜单栏的 **「订阅分组」**，点击 **「更新全部订阅（不通过代理）」**；
6. 几秒钟后，节点列表将自动填充出数十个国家地区的节点。

### 第三步：测速、选路与开启系统代理

1. 按 `Ctrl + A` 全选节点列表，鼠标右键点击并选择 **「测试服务器真实的延迟（多线程）」**；
2. 观察列表中返回的延迟毫秒数值，鼠标选中一个显示绿色低延迟的优质节点，按键盘 `Enter` 回车键（或右键设为活动服务器），该节点文字将变为高亮蓝色；
3. 在主界面最下方的工具栏中：
   - **路由（Routing）**：下拉选择 **「绕过大陆(Whitelist)」**；
   - **系统代理（System Proxy）**：右下角点击托盘图标，右键将系统代理设置为 **「自动配置系统代理」**（图标将由蓝色变为红色或紫色）。
4. 打开浏览器，即可正常浏览海外受限网站。

## Android 安卓端（v2rayNG）完整配置步骤

### 第一步：安装 APK

前往官方 GitHub 仓库（`2dust/v2rayNG`）的 Releases 页面，下载最新的 `v2rayNG_x.x.x_arm64-v8a.apk` 安装包。主流现代安卓手机均属于 `arm64-v8a` 架构。在手机上点击安装并允许安装未知来源应用。

### 第二步：导入订阅

1. 打开 v2rayNG，点击左上角三条横线的 **「汉堡菜单」**，进入 **「订阅分组设置」**；
2. 点击右上角 **「+」加号** 按钮；
3. 备注填写机场名称，在「可选地址 (url)」中粘贴订阅链接，点击右上角勾选保存；
4. 返回主界面，点击右上角三点菜单，选择 **「更新订阅」**；
5. 节点列表瞬间加载完毕。

### 第三步：分流与启动连接

1. 再次进入左侧菜单的 **「设置」**，找到「路由设置」下的 **「预定义规则」**，确保其勾选为 **「绕过局域网及大陆地址 (bypass lan and mainland)」**；
2. 回到主页面，在节点列表中点击勾选任意一个满意的节点；
3. 点击右下角的圆形 **「V」形连接浮动按钮**；
4. 手机系统会弹出建立本地 VPN 连接的权限确认请求，点击 **「确定」**。当按钮变为带有连接状态的绿色/橙色图标且状态栏出现钥匙图标时，代理即已成功接管。
