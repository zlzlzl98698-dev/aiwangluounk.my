## 一、四级金字塔式内链拓扑结构

网站架构形成了层次分明、自然流动的链接拓扑图：

```
                    【一级专题：L1 主题枢纽 (10 个)】
                    (/recommend/, /pricing/, /clients/, ...)
                                      ▲
                                      │ (向上汇报与横向跨主题互链)
                                      ▼
                    【二级专题：L2 细分指南 (60 个)】
                    (/recommend/best/, /pricing/cheap/, ...)
                                      ▲
                                      │ (向上归属 / 向下展开选题)
                                      ▼
             【三级长尾技术指南与横向对比 (37 篇)】
             (/guides/articles/{slug}/, /compare/{slug}/)
                                      ▲
                                      │ (具体痛点引导决策)
                                      ▼
             【品牌万字深度评测与商业详情 (31 个)】
             (/brands/{slug}/, /brands/reviews/, ...)
```

## 二、六大约束规则与自动映射执行

1. **三级文章向上归属**：所有 30 篇长尾指南和 7 篇对比文章顶部均配有清晰的面包屑导航（Breadcrumbs），点击可直接返回所属一级主题或对比中心；
2. **三级文章向同类互链**：每篇指南底部通过 `relatedLinks` 严格关联 3 至 5 篇高度相关的三级文章（例如在 `Clash Verge 安装教程` 底部推荐 `TUN模式设置` 和 `节点超时排查`）；
3. **三级文章通往品牌评测**：当长尾文章中提及具体品牌时（如光速云、飞猫云、二猫云），必须通过规范内链格式 `/brands/{slug}/` 引导读者进入独立评测；
4. **二级专题向下指路**：60 个二级专题页面的 `id="l3-clusters"` 区域，通过 `PUBLISHED_ARTICLES` 自动点亮已发布的文章标题，并打上高亮的「已发布」徽章，形成正向导流；
5. **品牌页反向关联技术指南**：每家品牌评测页面底部的 `relatedGuides` 均反向链接至 3 至 4 篇相关技术指南（如光速云关联 IEPL 原理、ChatGPT 分流教程）；
6. **零无效链接与死链**：全站所有内部链接均以斜杠结尾（符合 `trailingSlash: 'always'` 规范），经自动化脚本 `npm run qa`（37,000+ 链接检查）验证通过，无任何 404 坏死死链。
